# Nickolaj Ajay Atchuthan

I'm a biomedical engineer and PhD fellow at Aalborg University's Center for Neuroplasticity and Pain, working on nociception through experimental neuroscience and deep learning.

- **Neuroscience:** Experimental neurosurgery, nerve stimulation, and intracranial electrophysiology in anaesthetised pigs to study the dynamics of cortical responses.
- **Deep learning:** CNNs and model attribution for neural signals. I'm currently exploring a dual-branch vision transformer combining spectrograms and raw intracranial EEG to model stimulation-related brain activity.
- **Side projects:** Software built around my hobbies, from practical tools to larger applications, often involving machine learning and computer vision.
